# VLA最终交付视频结果与历史验证

在传统系统与示教基础上，项目进一步训练双视角π₀.₅，探索根据图像、状态与语言生成动作。本页优先展示最终交付30条视频统计，统一范围见[最终交付结果](FINAL_RESULTS.md)。

|类别|成功|失败|记录数|视频包内成功占比|
|---|---:|---:|---:|---:|
|苹果|9|1|10|90%|
|香蕉|7|3|10|70%|
|橘子|9|1|10|90%|

来源为[vla-cases30.zip](https://github.com/li2311675549/robot-vla/releases/download/v1.0.0/vla-cases30.zip)的清单及评分。记录从既有执行中按结果构成选取，包含重复初态，不是新一轮连续独立评测，不能估计总体成功率或与完整传统任务直接比较。

## 操作范围

已驻车十果桌面中，选中语言指定的具体水果，真实抬升至少55mm，最近1秒双侧接触比例至少90%，末帧仍夹持，并通过驻车与旁物保护。不包含入筐、5米导航或完整十果分类。

## 历史验证档案

历史固定30回合为14/30，苹果2/10、香蕉6/10、橘子6/10，覆盖6个验证布局和预声明噪声，非30个独立布局。另有历史40视频集合及全部68次执行账本；这些不是最终30条交付包的数量或构成。

历史结果仍保留在包内与[评测档案](EVALUATION_PROTOCOLS.md)，用于诊断目标选择和有效抬升等问题。本次文档更新没有新训练、新固定评测或成功率提升实验；视频包的选取不改变历史评测分母。
