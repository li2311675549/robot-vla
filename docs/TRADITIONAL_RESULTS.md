# 传统方法最终交付视频结果

本页按最终交付的传统70条视频及配套评分展示分项结果。完整口径见[最终交付结果](FINAL_RESULTS.md)。

|操作内容|成功|失败|记录数|视频包内成功占比|
|---|---:|---:|---:|---:|
|开门、入室、关门完整任务|10|0|10|100%|
|苹果抓取与放置|10|0|10|100%|
|香蕉操作|9|1|10|90%|
|橘子抓取与放置|10|0|10|100%|
|小书收纳|10|0|10|100%|
|中书收纳|10|0|10|100%|
|大书操作|7|3|10|70%|

这些是选取的展示记录，包含重复初态和不同开发版本，不是连续独立十回合成功率。水果和书本主要为单项操作；香蕉分组含已持物保持诊断，大书分组含不同范围的失败。完整5米接近、十果全入筐或三书返航应看完整父回合，不能由分项比例替代。

完整成功演示：[门](../media/demos/door_full.mp4)、[十果](../media/demos/fruit_full.mp4)、[三书](../media/demos/books_full.mp4)。
