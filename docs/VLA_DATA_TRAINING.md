# VLA：数据、归一化与实际训练配置

## 数据来源与训练分布

基础双视角数据173条/17646帧，新增复杂多果204次父操作拆为408个驻车片段/18949帧，覆盖76个上下文。新增父操作按场景隔离：train142、validation28、test34；不能把同一场景的片段随机拆到不同分区。

实际训练只用训练分区405片段、25517帧。旧单果121片段/12342帧；新3果32/1482、新5果70/3245、新10果182/8448。旧20%/新80%是冻结加权采样质量，不是简单按条数配比。十果对应91次单目标父操作、抓取91+放置91、34个训练布局；不是91次完整清空十件。

十果预期采样质量约51.252955%。原十果父操作全部124次中train91、validation14、test19。验证/测试不参与训练或归一化统计。原始数据位于独立桌面数据目录，避免复制庞大图像/深度到GitHub源码包。包内提供数据说明、索引和统计；没有这些原始数据，不能仅凭视频恢复训练标签。

## 质量与动作语义

Schema3统一高层绝对关节目标和夹爪，另存reference/ctrl、双RGB、深度、实际状态、指令、阶段、时间戳、种子与结果。新408片段已做高频及5Hz控制器物理重放；这是数据/专家重放通过，不是学习模型成功率。失败轨迹单独保留，不纳入正样本。

图像和状态必须与动作起点对齐。训练和推理同用5Hz/10步chunk/绝对目标，不重复做增量变换或重力补偿。旧不同语义数据不得不经适配混入。

## 归一化

仅训练分区计算，状态按采样起点分布，动作按10步chunk及episode末端clamp后的权重计算；与旧20%/新80%采样一致。π₀.₅使用quantile规范化；mean/std/q01/q99均保留。

实际训练norm SHA256：`2315f953b3ee8949915f315b9c938ef6f0ca7a5e9397562d82c238d90b4c67c8`。检查点内统计已与冻结train-only资产逐语义核验。包内附从当前服务器只读下载的9999归一化文件，不包含模型参数。

## 依赖和迁移

本地MuJoCo为Python3.10，服务器训练为独立Python3.11 OpenPI环境；不能混装。实际OpenPI源码、`uv.lock`、`pyproject.toml`和许可证已从无卡服务器下载，逐文件SHA校验。远端为源码导出，不能虚构不存在的上游Git提交。

完整权重、Tokenizer与训练原始数据不纳入GitHub源码。基础权重和检查点按各自许可保存/分发；完整9999仍在服务器持久化数据盘。恢复训练或推理需要实际权重、相同norm、原始数据与合适GPU，不会因本次归档自动启动。

下一步研究重点是十果场景目标选择、接触闭环、独立布局覆盖及抓取到放置链路。继续训练不保证解决这些问题；应与同初态传统专家配对评估，保留全部失败和正式测试隔离。
