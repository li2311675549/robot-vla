# 任务定义、验收边界与当前能力

## 三类完整移动操作

1. 单扇铰链门初始关闭，机器人从门外约5m靠近，抓把手拉开，整机进入房间后关门。
2. 从桌前约5m出发；10个随机水果，苹果/香蕉/橘子均出现，同类有尺寸/外形差异；三个清晰标识的有碰撞边界收纳筐；全部正确入筐。
3. 从桌前约5m出发；三本不同大小书随机摆放；按面积大小放第一/二/三层，关闭抽屉并返航。

每个完整任务按冻结协议连续独立10回合，全部失败与超时计入；报告完整成功率及完成时间。视频、环境、模型、源代码和技术依据分别交付。

## 当前实现与限制

三类传统完整任务均有真实连续成功视频。当前成果入口按[最终交付视频分项结果](FINAL_RESULTS.md)展示，旧完整任务测试单独保留为[历史评测档案](EVALUATION_PROTOCOLS.md)。成功实例、视频包构成和独立完整任务可靠性分别说明；旧协议数字不直接代表当前main版本的新成绩。

门采用1.57m宽门洞和Oracle几何专家，不代表窄门或纯视觉。水果旧布局与新版散落布局分别保留，不能以旧布局重复成功视频替代新版正式成功率。三书120×80×15、180×120×20、240×160×25mm，与历史窄小册子协议分开。

1600秒是历史内部超时，不是原始任务硬限。采用3000秒开发/冻结协议的结果不能记为1600秒协议通过。仿真时间、墙钟时间和成功回合平均时间分开。

## VLA与完整任务区别

VLA目前的十果录像只验证驻车单目标按指令抓起保持；没有放入筐、没有完整清空10件、没有5m移动过程。最终交付为30条展示记录，苹果9/10、香蕉7/10、橘子9/10；记录经选取并包含重复初态。历史固定验证和历史40段集合单独保留，不作为最终包的数量与构成。

不能把展示比例当正式独立成功率，也不能把数据物理重放、pytest、loss下降或模型接口通过当成完整任务通过。原版UR5身份、正常锁边把手、真实轮驱、接触物理和所有失败记录必须保留。
