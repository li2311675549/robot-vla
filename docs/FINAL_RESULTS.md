# 实验结果与视频

本页列示与[README](../README.md)及[当前结构化结果索引](../evidence/current_benchmarks.json)一致的**最新对外公布操作记录**。传统视频使用v1.1.0-speed包，VLA沿用v1.0.0包，均不代表本次重新运行了实验或重新训练模型。

每项10条记录按指定构成整理，存在重复初态；传统包的部分失败来自早期开发版本。因此下表的成功比例仅对应**这些已发布记录的实际构成**，不是同一冻结策略的连续独立随机评测。请勿将单项操作统计与十果分类或三书收纳的完整任务成功率互换。

## 完整父回合执行时间

|完整父回合|真实成功父回合数|平均仿真时间|
|---|---:|---:|
|门完整流程|10|116.264s|
|全部十果入筐|4|705.274s|
|三书关屉并返航|10|438.424s|

上表来自已知开发初态的完整物理复跑；“成功父回合数”不是“尝试总数”，不得据此推算完整任务成功率。它仅用于报告这些成功回合的执行用时。外部录像视角变化不等于场景泛化；仿真秒与墙钟时间分开保存，渲染硬件不同会影响墙钟速度。

## 来源与失败范围

门记录为完整任务。水果与书本为各自父回合中的连续单对象片段，不拼接不同回合冒充完整成功。香蕉失败是旧速度版本搬运导航超时；大书失败是旧版本路径/碰撞预检或关屉停车保护，不等于书本实际掉落。所有原始成功、失败和基础设施中断均保留于本地账本，中断未计为物理失败。

成功素材使用当前各任务已成功的冻结速度策略；失败素材来自明示的旧开发版本。因此不能把包内比例解释成该新策略的测得成功率。所有10条的平均终止时间另列于附件manifest，不与成功完成均时混合。
