# 旧版实验记录（仅作版本追溯）

本目录保留早期冻结协议的汇总数据，避免旧统计文件继续被理解为当前对外发布结果。历史记录的数值、失败归因和源路径保持不变。

- [previous_full_task_benchmarks.json](previous_full_task_benchmarks.json)：此前位于 `evidence/current_benchmarks.json` 的门/十果完整任务/散落三书整轮结果原文归档。
- [vla_fixed30.json](../issues/vla_fixed30.json)：早期驻车VLA固定布局的30回合诊断，和当前发布的30条抓起/保持视频构成不是同一记录集合。
- [books_formal_summary.json](../issues/books_formal_summary.json)：历史散落三书完整任务冻结协议。
- [door_contact_acceptance.json](../issues/door_contact_acceptance.json)：历史正常门任务冻结验收，执行时间统计不同于最新发布操作记录。

**当前公布的10组成功次数和记录占比**请以[README](../../README.md)、[结果页](../../docs/FINAL_RESULTS.md)和[当前结构化索引](../current_benchmarks.json)为准。这一“当前”指发布版本的操作记录，而非声明已完成一个未披露的连续独立随机评测；如需声称该性质，必须另行提供完整逐回合日志及测试协议。

旧版的十果/三书**完整任务**与当前单件操作统计的分母、任务单位及协议不同，不能以任何一组结果直接替换另一组。
